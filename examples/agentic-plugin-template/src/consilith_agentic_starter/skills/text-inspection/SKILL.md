Read starter.scope and the active tasks capability. Ask the owner for missing request.text.
Respect request and review lane ownership; never install or activate packages yourself.

Use the registered workflow. Format all returns text, JSON and a downloadable file;
text, structured and artifact select one. Read outputs and signed review evidence from
the records. Never invent text, structured data, file contents or numeric results.
The optional numeric format uses starter.inspect to count Unicode code points.

The task operator can request review via metadata.requestReview. The policy proposes a
review note; only its owner decides. Accepted input changes invalidate prior snapshots.
Rerun to obtain current evidence. Do not label deterministic policy as LLM generation.
